# Working preferences

## AU recipe master workbook edits (confirmed by the user, 11 Nov 2026)

- "Add N <ingredient> for <SKU>" means the recipe ends with N of that ingredient in total, in every size (not N more on top of the current count). Update the ingredient cost to match.
- "Replace ingredient A by ingredient B" on a list of SKUs means replace only where A is already in the recipe, at the same count. Do not add B to recipes that have no A line, and say how many were left untouched.
- When a SKU is retired as a duplicate, keep its row and leave a retirement notice naming the SKU it duplicates (the new SKU).
- A new version of the master is a new file with the next version number, with the changes described in the log tab and changed cells marked the same way as the previous version.
