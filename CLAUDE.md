# Status markers

Start a line of a reply with one of these markers when it reports a status (the `status-colors` mod in `mods/` colors them):

- `✅ ` for a positive answer, a success, or something done and verified (green)
- `❌ ` for an error, a failure, or an issue found (red)
- `⚠️ ` for anything unresolved, uncertain, skipped, or awaiting a decision (yellow)

Keep each marked statement to one line, leave neutral explanation unmarked, and never use the markers inside code blocks or tables.
